# TaskFlow
The Task Management Application is a React.js project used to manage daily tasks easily. Users can log in, view tasks, add new tasks, edit tasks, delete tasks, and update task status.  The project uses React concepts like components, hooks, routing, API integration, and CRUD operations. It also has a responsive and user-friendly UI design.

# TaskFlow - Task Management Application

## Feature List

- User login page with:
  - Full Name input
  - Email input
  - Password input

- Home dashboard with:
  - Welcome banner
  - Task statistics cards

- Task Statistics:
  - Total Tasks
  - In Progress
  - Completed
  - On Hold

- Task filtering by status:
  - All
  - In Progress
  - Completed
  - Hold

- Task search input UI

- Add New Task page with:
  - Task Name field
  - Status selector
  - Assigned To field

- Edit and Delete task functionality

- Client-side validation for required fields

- Navigation using React Router:
  - `/` → Login Page
  - `/home` → Home Dashboard
  - `/add-task` → Add Task Page

- Responsive UI design using separate CSS files

- Uses remote API data from:
  - `https://jsonplaceholder.typicode.com/todos`
